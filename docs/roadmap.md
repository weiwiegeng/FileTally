## 三、技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| SMB 协议 Rust 库不稳定 | 远程连接功能受阻 | 备选方案：通过系统命令挂载 |
| 大量文件性能问题 | 用户体验下降 | 分批加载 + 进度反馈 |
| PDF 复杂格式解析失败 | AI 分析功能受限 | 多库备选 (pdf-extract, pdfium) |
| OpenAI API 访问限制 | AI 功能不可用 | 支持本地模型 (Ollama) |
| 跨平台兼容性问题 | 部分平台功能异常 | 提前多平台测试 |
