# FileTally 功能设计文档

## 一、功能总览

| 模块 | 核心功能 | 优先级 |
|------|----------|--------|
| 磁盘监控 | 自动检测磁盘空间与数量 | P0 |
| 文件浏览 | 层级展示文件夹内容、文件预览 | P0 |
| 远程连接 | 连接 NAS/远程存储系统 | P1 |
| 规则筛选 | 自定义规则筛选文件 | P1 |
| AI 分析 | PDF 内容智能分析 | P2 |

#### 支持的规则类型

| 规则类型 | 操作符 | 示例 |
|----------|--------|------|
| 文件名 | 包含、不包含、开头、结尾、正则 | `名称包含 "report"` |
| 扩展名 | 等于、在列表中 | `扩展名 = pdf` |
| 文件大小 | >, <, =, >=, <= | `大小 > 100MB` |
| 修改时间 | 在...之前/之后、最近N天 | `修改于最近7天` |
| 创建时间 | 在...之前/之后、最近N天 | `创建于 2024年` |
| 文件类型 | 等于 | `类型 = 图片` |
| 路径 | 包含、不包含 | `路径包含 "backup"` |

#### 数据结构

```typescript
interface FilterRule {
  id: string;
  field: 'name' | 'extension' | 'size' | 'modified_time' | 'created_time' | 'type' | 'path';
  operator: 'contains' | 'not_contains' | 'equals' | 'not_equals' | 
            'starts_with' | 'ends_with' | 'regex' |
            'greater_than' | 'less_than' | 'between' |
            'before' | 'after' | 'within_days';
  value: string | number | [number, number];
}

interface FilterGroup {
  id: string;
  name: string;
  logic: 'AND' | 'OR';
  rules: FilterRule[];
  created_at: number;
}
```

## 三、交互设计原则

| 原则 | 说明 |
|------|------|
| 自动检测 | 磁盘扫描、权限请求由系统自动检测并弹出 |
| 层级清晰 | 大量内容采用层级树形结构，支持展开/折叠 |
| 懒加载 | 仅加载可视区域内容，提升性能 |
| 即时反馈 | 操作后立即给予视觉反馈 |
| 科技感 | 采用现代化设计语言，深色主题可选 |

## 四、错误处理

| 场景 | 处理方式 |
|------|----------|
| 磁盘访问权限不足 | 弹出系统授权请求对话框 |
| 远程连接失败 | 显示错误原因，提供重试选项 |
| 文件无法预览 | 显示文件信息，提示不支持的格式 |
| AI 服务不可用 | 显示离线提示，建议配置 API |
| 大文件加载 | 显示进度条，支持取消操作 |
