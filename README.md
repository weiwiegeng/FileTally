# FileTally

跨平台智能文件管理器（Tauri 2 + React）。面向本地磁盘与局域网 NAS：浏览、预览、搜索、传输，以及对大目录 / 远程共享的智能检查与分析。

## 功能概览

| 模块 | 一句话 |
|------|--------|
| [磁盘监控](#磁盘监控) | 本机分区容量与占用一览 |
| [文件浏览](#文件浏览) | 多标签、收藏/最近、树/列表视图 |
| [远程连接](#远程连接) | SMB / WebDAV / SFTP；钥匙串记住密码 |
| [智能搜索](#智能搜索) | 内容检索、结果过滤、可选本地索引 |
| [文件传输](#文件传输) | 本地 ↔ 远程、限速、任务中心进度 |
| [规则筛选](#规则筛选--批量整理--同步) | 扩展名/大小/时间/路径规则 |
| [批量整理](#规则筛选--批量整理--同步) | 重命名、按类型归类、删空目录（预览+撤销） |
| [轻量同步](#规则筛选--批量整理--同步) | 单向镜像对比与同步 |
| [智能检查](#智能检查) | Excel 名单 ↔ 目录核对（含直连远程） |
| [智能分析](#智能分析) | 空间统计、清理建议、AI 解读 |
| [任务中心](#任务中心) | 搜索/传输/检查/分析/同步统一进度与取消 |

大目录扫描在后台执行，带进度与取消；UI 侧有软上限避免卡死。

### 磁盘监控

- 自动发现本机挂载分区（含可移动磁盘）
- 展示总容量、已用 / 可用空间与占用比例
- 支持手动刷新

### 文件浏览

- 多标签根目录；收藏夹与最近路径
- 树形懒加载 + 列表视图（虚拟表格）
- 预览：PDF、Excel、Word、图片、音视频、文本/代码
- 排序、隐藏文件、预览面板位置可配置

### 远程连接

- **SMB**：应用内直连（`remote://`）或系统挂载
- **WebDAV / SFTP**：统一 `remote://{id}/…` 路径
- 密码可写入系统钥匙串，重启后自动填充并重连
- 直连模式下可用列表浏览子目录

### 智能搜索

- 文件名 / 路径 / 内容；远程目录；结果按类型过滤
- 可选对本机根目录建 SQLite 文件名索引
- 超时、并发、缓存可在设置中调节；任务进入任务中心

### 文件传输

- 本地 ↔ NAS/远程双向；冲突策略；进度进任务中心
- 可设带宽上限（MB/s）与并发（1–2）

### 规则筛选 / 批量整理 / 同步

- **规则筛选**：扩展名、大小、修改天数、路径正则；规则可保存
- **批量整理**：规则重命名、按扩展名归类、删除空目录；先预览再执行，可撤销
- **轻量同步**：源 → 目标单向对比（新增/变更/多余），再执行同步

### 智能检查

- Excel 比对与完整性检查（`{name}` 模板）；名单 ↔ 目录核对
- 检查方案可保存；本地与直连远程均可全树扫描，可取消

### 智能分析

- 类型分布、大文件、重复组、旧文件；可取消
- 清理建议；AI 解读（仅基于统计，不读原文）
- 文档助手需配置模型（含国内厂商）

### 任务中心

- 统一查看运行中与历史任务，支持取消

### 设置与体验

- 中英文；深色 / 浅色 / 跟随系统
- AI：OpenAI、Claude、Ollama、DeepSeek、智谱、通义、Kimi、混元等

## 技术栈

| 层 | 技术 |
|----|------|
| 桌面壳 | Tauri 2 |
| 前端 | React 19、TypeScript、Vite、Ant Design 6、Zustand、i18next |
| 后端 | Rust（文件系统、SMB/WebDAV/SFTP、扫描与传输） |

## 快速开始

**环境：** Node.js 18+、Rust 1.70+、npm

```bash
npm install
npm run tauri:dev
npm run tauri:build
./build.sh windows   # 或 macos / all → release/
```
